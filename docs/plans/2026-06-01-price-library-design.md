# 价格库 + 智能填充设计方案

## 概述

在现有报价系统基础上，增加价格库功能：自动记录历史报价数据，新报价时智能匹配并自动填充项目特征、单价、备注，形成自学习闭环。

## 核心价值

- 新报价只需填 分类+名称+数量，AI 自动补全其余信息
- 报价完成后自动入库，价格库越用越丰富
- 支持从历史 PDF/Excel 批量导入

## 触发方式

| 命令 | 功能 |
|------|------|
| `/填充 [链接]` | 查询价格库，自动填充当前报价 |
| `/报价 [链接]` | 生成 PDF + 自动入库 |
| "导入历史报价" + 文件 | 批量导入历史数据到价格库 |
| "查看价格库" | 展示价格库统计 |

## 数据架构

### 价格库多维表结构

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 工程分类 | 单选 | 13 类标准工程分类 |
| 项目名称 | 文本 | 条目名称（用于匹配） |
| 项目特征 | 文本 | 默认特征描述 |
| 单位 | 单选 | ㎡/项/m/套 等 |
| 综合单价 | 数字(货币) | 历史价格 |
| 备注 | 文本 | 默认备注 |
| 最后使用日期 | 日期 | 最近一次被引用的时间 |
| 使用次数 | 数字 | 被引用的累计次数 |
| 来源 | 单选 | "历史导入"/"手动添加"/"报价自动入库" |

## 自动填充工作流

### 流程

```
用户在多维表填好：分类 + 名称 + 数量
        ↓
触发：/填充 [链接] 或 "帮我填充报价"
        ↓
AI 读取多维表所有条目
        ↓
逐条查询价格库
        ↓
精确匹配 → 自动填充，标记"已填充"
模糊匹配 → 列出候选，让用户选择
无匹配   → 标记"待填写"，跳过
        ↓
回写多维表（项目特征 + 综合单价 + 备注 + 合价）
        ↓
回复用户：填充结果摘要
```

### 回写字段

| 字段 | 填充逻辑 |
|------|---------|
| 项目特征 | 从价格库直接复制 |
| 综合单价 | 从价格库直接复制 |
| 备注 | 从价格库直接复制 |
| 合价 | 自动计算：数量 × 综合单价 |

### 不修改的字段

工程分类、项目名称、数量 — 由用户控制，AI 不动。

## 价格库自动更新

### 入库时机

PDF 生成成功后自动执行。

### 入库逻辑

- 按项目名称匹配已有条目
- 已存在 → 使用次数 +1，更新最后使用日期
- 不存在 → 新增条目，来源标记"报价自动入库"
- 价格冲突时不自动覆盖，回复用户确认

## 历史文件批量导入

### 处理流程

```
用户提供 PDF/Excel 文件
        ↓
Step 1: AI 解析文件，提取原始条目列表
        ↓
Step 2: 标准化处理
  - 统一单位（㎡ → ㎡）
  - 统一分类名称（映射到 13 类标准分类）
  - 清理特殊字符和格式
        ↓
Step 3: 智能去重
  - 与价格库现有条目比对
  - 名称相似度 > 80% → 视为同一项目
  - 合并：取价格库已有特征 + 用户确认价格
        ↓
Step 4: 回显给用户确认
  "从文件中提取了 X 条，去重后 Y 条：
   - 新增：Z 条
   - 合并更新：W 条
   - 确认导入？"
        ↓
Step 5: 用户确认后写入价格库
```

### 价格冲突处理

- 新价格 > 旧价格 → 提示"建议更新为新价格"
- 新价格 < 旧价格 → 提示"新价格低于历史，是否保留旧价格？"
- 由用户最终决定，不自动覆盖

## 整体架构

```
价格库（飞书多维表）
    ↑ 自动入库（报价生成后）
    ↑ 手动导入（历史文件）
    ↓ 自动查询（填充时）

新报价流程：
1. 用户填 分类+名称+数量
2. /填充 → AI 自动填充 特征+单价+备注
3. 用户确认/调整
4. /报价 → 生成 PDF + 自动入库
```
